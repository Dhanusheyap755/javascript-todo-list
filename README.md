# TaskFlow — JavaScript Logic & State Management

A responsive client-side To-Do List built with HTML5, CSS3 and vanilla JavaScript.

## Features

- Create tasks
- Read/display tasks dynamically
- Update task text
- Mark tasks as completed/active
- Delete individual tasks
- Filter by All / Active / Completed
- Clear all completed tasks
- Persist data with `window.localStorage`
- Dynamic DOM manipulation
- Event listeners for interactions
- Responsive mobile-friendly design
- Accessible labels and live task updates

## How to run

Open `index.html` directly in a modern browser.

No server, framework, package manager, or installation is required.

## Files

- `index.html` — application structure
- `style.css` — responsive styling
- `script.js` — CRUD, state management, DOM manipulation, events and localStorage
