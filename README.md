## 📌 Project Overview
An interactive productivity and task tracking application built entirely with **Vanilla JavaScript (DOM manipulation)** and persistent browser **LocalStorage**. It allows users to manage their daily agendas with item creation, completion toggles, priority tagging, and filtered views.

---

## 🚀 Key Features
- **Client-Side Persistence:** Tasks remain saved across browser reloads using HTML5 `localStorage`.
- **Dynamic Filtering:** Filter tasks instantly across All, Active, and Completed categories.
- **DOM Event Delegation:** High-performance event handlers managing state transitions.
